# brain-pages

This repository hosts the built static output for **www.gobrain.org**.

Do not edit files here directly — this repo is overwritten on every deploy by the
`deploy-other-sites` job in [BRUserGroups/brusergroups-site](https://github.com/BRUserGroups/brusergroups-site)'s
`.github/workflows/deploy.yml`. Source content lives in that repo's `sites/brain/` directory.

GitHub Pages source: **Deploy from a branch** → `main` → `/ (root)`.
